# Adam's Middle-earth homepage — art handoff

Give this entire folder to Codex and ask it to execute CODEX-PROMPT.md. Read PLACEMENT-GUIDE.md for the visual plan.

Includes seven original, unmodified generated PNGs and a pixel-dimension/SHA-256 manifest. These are native 1024–1536-pixel assets, NOT 2K/4K masters. Earlier generation requests for 2048px did not produce 2048px files. No artificial upscaling has been applied. The icon atlas contains 12 icons, not 12 full-resolution individual masters. Extracted icons are suitable for small UI use, not large hero art.

All images have alpha channels. Frame center pixels are fully transparent; scroll and door centers are intentionally opaque/nearly opaque. Some generated metal ornaments have soft translucent halos. Inspect over the actual page background before shipping. Do not remove black globally: dark stone and raven feathers are intentional.

The pack contains artwork and implementation instructions, not a completed website or tested CSS. Existing screenshots were used for planning but are not included because they contain personal email information. The beloved existing hero/header and original Frear character image are already in the site and are not duplicated here.
